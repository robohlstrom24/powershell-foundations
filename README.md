## Operational Relevance (IT Operations and Automation)

This project demonstrates fundamental PowerShell skills relevant to an IT Operations environment. Shell demonstrations model standard workflows, including archiving files by age and event log triage. A reusable asset inventory script is included to demonstrate basic automation for endpoint inventory and reporting. Outputs are generated in structured formats to support review, reuse, and safe execution in operational contexts.

## Job Duties (IT Operations / PowerShell)

- Performing routine file system hygiene tasks  
- Conducting basic event log triage  
- Collecting and reporting endpoint inventory data in structured output formats  
- Producing safe, repeatable command-line workflows and artifacts suitable for review, documentation, and reuse
